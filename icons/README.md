# Icon Dosyaları

Bu klasöre aşağıdaki boyutlarda PNG icon dosyaları eklemeniz gerekmektedir:

- `icon16.png` - 16x16 piksel
- `icon48.png` - 48x48 piksel  
- `icon128.png` - 128x128 piksel

Icon dosyaları olmadan da eklenti çalışır, ancak Chrome'da görsel olarak eksik görünebilir.

Basit bir icon oluşturmak için herhangi bir görsel düzenleme programı kullanabilirsiniz.
